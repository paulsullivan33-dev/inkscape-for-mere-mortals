# What Inkscape Is

You have a picture in mind — a logo, a
diagram, a label — and you want it to
stay sharp wherever it lands: small on
a web page, large on a printed poster,
cut into vinyl or etched onto a badge.
The familiar kind of computer picture
cannot promise that. A **raster**
picture (a photo, a PNG, a JPEG) is a
grid of pixels, tiny coloured squares,
and the grid is fixed the moment the
picture is saved. Show it bigger than
its grid and the computer has to guess
the in-between squares; the picture
goes soft, then blocky.

**Inkscape draws the other kind of
picture.** A **vector** drawing stores
no grid at all. It stores a list of
shapes, each described by numbers: this
circle sits at (120, 120) with radius
112; this star has these ten corners;
this curve bends through these points.
When the picture is shown — on a
screen, in a browser, at a printer —
the shapes are drawn fresh, at exactly
the size requested. Small or enormous,
the edges come out clean, because they
are computed, not enlarged. Chapter 6
proves it with the guide's own badge:
one file, exported at 96 pixels wide
and at 480, both sharp, the bigger one
simply containing more pixels of the
same truth.

## The file is text

Inkscape's native format is **SVG**
(Scalable Vector Graphics), and SVG is
text — ordinary XML, the same family
as a web page's HTML. The badge this
guide uses for everything is 1,472
bytes of it, and chapter 4 prints the
whole file and reads it line by line.
A circle really is written

```xml
<circle id="ring" cx="120" cy="120" r="112"
        fill="#fdf6e3" stroke="#264653" stroke-width="6"/>
```

and that is the entire circle. This has
a practical consequence the guide leans
on throughout: a drawing can be
written, read, searched, generated by a
script, and checked by a program —
including Inkscape itself, asked from
the command line where every shape is.
It also means your drawings play well
with the web: every modern browser
shows SVG directly, so chapter 4's
first check of your first drawing needs
no special software at all.

## A first taste

After installing (chapter 3), nothing
stops you asking a drawing about
itself:

```bash
inkscape badge.svg --query-all
```

```text
ring,5,5,230,230
disc,56.5,64.5,127,127
star,82.7502,84.7502,74.4996,68.3997
```

Each line names an object and reports
where its edges fall. No window opened;
the drawing answered from the file
alone. Chapter 5 is about those
numbers, and chapter 7 changes them on
purpose — scaling the star by exactly
one and a half, then measuring again to
watch the width obey: 74.4996 becomes
111.749.

## What it is not

Inkscape is not a photo editor: it
cannot retouch a portrait or fix a dark
exposure, because a photo has no shapes
to edit, only pixels — that is GIMP's
world, and this series has a guide for
it. It is not an engineering tool:
nothing here holds a tolerance or a
thread size, and chapter 11 points at
the CAD guides for drawings that must
fit other parts. It is not a page
layout program for books. And it is
not, despite living in text files, a
programming language: the text is a
description of shapes, and Inkscape is
the thing that draws them.

## Who it is for

The maker who needs a logo that
survives both a web page and a market
stall banner. The writer whose book
needs diagrams that stay crisp in
print. The hobbyist feeding a laser
cutter or a vinyl cutter, both of which
eat vector files. The programmer who
would rather generate a chart's frame
than draw it twice. The common thread
is one person, one drawing, and the
wish for it to come out right at any
size — free, on their own machine, in a
format nothing owns.

## The honest catches, up front

Two, and this guide treats both as part
of the telling. First, **the lab had no
screen**. Everything in these pages was
done from the command line and proved
by measurement; drawing with the mouse,
which is how Inkscape is normally used,
is taught from the documentation and
labelled. The command line is a full
citizen here, not a fallback — but the
guide says plainly which parts it ran
and which it only read, and
`criteria.md` keeps the ledger.

Second, **Inkscape forgives**. A
missing file, a misspelled object name,
even a drawing file cut off in the
middle all produce something, quietly,
with a success exit code. Chapter 13
walks through the three traps; the
defence, everywhere in this guide, is
the same habit: check the output, never
trust the exit code.

One more line, drawn early because
later chapters lean on it. Inkscape
can *trace* a pixel picture — turn a
scanned sketch into paths — and that is
a fine way to start a drawing of your
own. Tracing someone else's artwork
does not make it yours, and the fonts
your lettering uses carry licences of
their own. Chapter 9 comes back to
both.
